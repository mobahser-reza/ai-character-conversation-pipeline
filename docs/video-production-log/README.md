# Video Production Log

One file per produced sample video goes here, e.g. `001-intro-conversation.md`, with:
what script was used, which providers/keys were active, the final aspect ratio,
the output URL/file, and any notes on retakes or prompt tweaks.

Populated once real provider API keys are supplied and the first 4-5 sample
videos are generated (see project plan phase 10 — this is the one phase that
depends on the user's own vendor keys/budget rather than on code).
